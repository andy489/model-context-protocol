# Model Context Protocol

Course notebooks and materials for learning the Model Context Protocol (MCP).

## Courses

- [Introduction to MCP](./01-introduction-mcp/README.md) — Core concepts, architecture, advantages, and real-world usage patterns of MCP
- [MCP in Practice](./02-mcp-practice/README.md) — Building, distributing, and securing MCP servers with TypeScript and C#
- [FastMCP Foundations](./03-fastmcp-foundations/README.md) — Building MCP servers with FastMCP: architecture, middleware, observability, and production deployment
- [MCP Advanced Features](./04-mcp-advanced-features/README.md) — Filters, completions, notifications, stateful clients, roots, elicitations, sampling, custom Python clients, and agentic workflows on Cloudflare Workers
- [Agent-to-Agent (A2A) Protocol](./05-agent-protocol/README.md) — A2A architecture and core concepts, building agents across frameworks (OpenAI Agents SDK, LangGraph, CrewAI), orchestration patterns, and production deployment
- [Using the C# MCP SDK](./06-using-c#-mcp-sdk/README.md) — Building, securing, and deploying MCP servers with C#: tools, OAuth, AI agent integration, and NuGet publishing

## Labs

Hands-on labs for building MCP servers from scratch.

- [Build a Simple MCP Server](./labs/01-build-simple-mcp-server/README.md) — Build a minimal MCP server with FastAPI and Pydantic, implementing tool discovery and execution
- [FastMCP Corporate Assistant](./labs/02-fastmcp-corporate-assistant/README.md) — Build a production-ready MCP server with FastMCP exposing resources, prompts, and tools for a corporate assistant
